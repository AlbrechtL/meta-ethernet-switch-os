Set up the admin account

The switch has no admin account yet. Choose its username and password: they log in to this web interface, over SSH and on the serial console. Until then, SSH lets nobody in. The username can only be changed again with a factory reset.

Changes are active but not saved: a reboot undoes them. Use Save configuration to keep them.
